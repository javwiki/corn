# 业界主要奖项

## 评选与记录口径

- **获奖与提名分开**：同一类别中，提名不等于获奖；条目表格的「结果」列应明确写「获奖」或「提名」。
- **年份口径**：通常写颁奖典礼举办年份；若来源按作品发行年份统计，应在条目中说明。
- **类别名称**：保留机构公布的英文类别名，便于与官方名单核对；中文可作辅助翻译。
- **粉丝奖与行业奖**：Pornhub、NightMoves 粉丝选择、Fleshbot 等以粉丝投票为主；AVN、XBIZ、XRCO 等以行业或评论界评审为主，引用时不宜混为一谈。
- **停办与复办**：GayVN、Urban X 等曾停办后恢复，跨年份比较时需注意届次断层。
- **垂直奖项**：Spank Bank、AltStar、Inked 等小型或垂直奖项也会出现在人物条目中，引用时同样以官方名单为准。
